# Agentic-AI

This repository is a lightweight starter for building an agentic AI workflow

## What is included

- A simple Python example of a prompt-driven agent loop
- A basic project README for onboarding and experimentation
- A clean Git ignore file for Python projects

## Example usage

```bash
python agentic_ai.py
```

## Project goals

This project can be used as a base for:

- LLM-powered agents
- tool calling workflows
- multi-step reasoning chains
- lightweight experimentation and prototypes

## Next steps

- Add your own tools and model client
- Extend the agent loop with memory or planning
- Connect to APIs, databases, or browser automation
